==========================================
 TEAPOT COMPILER PACK v4.0
==========================================
WAD COMPILER:
- Put .bmp files here.
- Run. It will assign numbers (1, 2, 3...) to files.
- Refer to 'Texture_List.txt' to see which number is which.

MAP COMPILER:
- BOX [x] [y] [z] [size] [ID]
- SPRITE [x] [y] [z] [ID]
- SPRITE_MOVABLE [x1][z1] [x2][z2] [y] [speed] [ID]

NOTE: [ID] is the number from Texture_List.txt

The Map Compiler puts the compiled.bs2 file inside
bin\maps
