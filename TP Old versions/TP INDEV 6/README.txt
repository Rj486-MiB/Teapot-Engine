=========================================
 TEAPOT ENGINE - Build 6.3
=========================================

SYSTEM REQUIREMENTS:
- Windows 98-10
- Software.dll & Loader.dll in bin/

INSTRUCTIONS:
1. Ensure your Map.bs2 is in TP\bin\maps\
2. Ensure your Texture.wad is in TP\bin\materials\
3. Run Teapot.exe

CONTROLS:
- W / S : Move Forward / Backward
- Left / Right Arrow : Rotate Camera

CONFIG:
Modify bin\config.ini to enable the Debug Console:
[Settings]
Cons=True

(if config.ini is missing run Teapot.exe once then it will appear)
